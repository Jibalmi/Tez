Typed decisions from one forward pass.

An open, local decision engine: ask typed questions about a message and get a calibrated probability for every answer. No tokens are generated.

Needs Python 3.10 or later and llama.cpp's llama-server hosting a Gemma 4 12B GGUF on port 8091. Quickstart

Read the answer instead of generating it.

Tez writes the question and its options first and the input last, runs one forward pass, and reads the probability of each option's letter at the position where the model would start to answer.

  1. Options first, input last

    The instructions and options are the same for every decision, so llama.cpp keeps them cached and evaluates only the input. When a message streams in, only the new words are evaluated.

  2. One forward pass, no generation

    The model reads the prompt once. Tez stops at the answer position and takes the next-token distribution over the option letters. This is the zero-shot letters readout.

  3. Or a probe on a middle layer

    With 25 to 50 labels per question, tez fit trains a logistic probe on a middle layer's hidden state. The served probe model is Qwen3.5-4B cut to 24 of its 32 blocks, so the top of the network never runs.

  4. A calibrated distribution out

    Every option gets a probability. Choice and score answers carry a confidence, and an abstain option and a conformal gate mark what to act on and what to escalate.

Speaks the /v1/systemone wire format.

Tez serves TypeSafe's /v1/systemone request and response shapes on http://127.0.0.1:8787, so a client written for Jev's wire format can point its base URL at your machine.

Same answer shapes
noul is P(yes); choice and score carry probabilities and confidence, exactly as Jev returns them.
Optional extensions
schema and a tez block for readout, abstain and the gate. Strict clients ignore them.
Same error codes
401 without a valid key (only when the server sets one), 422 for an invalid request, 503 when llama-server is down.

Knows when not to decide.

Every answer is a distribution, so Tez can hold back: an abstain option for inputs that fit none of the options, and a conformal gate that acts only while the error rate among acted decisions stays under the bound you set.

confidence
On choice and score answers, (k·pmax − 1)/(k − 1): 0 when every option is equally likely, 1 when one option holds all the probability.
"tez": {"abstain": true}
Adds __none__, "none of these fits", to every choice question.
"tez": {"gate": {"alpha": 0.05}}
Marks each answer act or escalate. Acting needs a schema fitted with tez fit; a question without a calibration always escalates.

Runs on your machine.

llama.cpp hosts an open GGUF model, tez serve answers on 127.0.0.1, and no request leaves the machine. There is no hosted Tez service.

Where Tez runs, what it runs and how fast
Reference hardwareRTX 5080 laptop GPU, 16 GB. Every number on this site was measured on it.
Servingllama.cpp llama-server (build b11100) hosts the GGUF; tez serve speaks the wire format on 127.0.0.1:8787.
Default modelsGemma 4 12B Q8_0 for zero-shot letters. Qwen3.5-4B cut to 24 of its 32 blocks for probes.
Per streamed word30 ms compute, 45 ms round trip (p50) for voice commands: 16 actions in a cached prefix, llama-server run with --swa-full.BENCHMARKS.md §3
Per decision57–250 ms p50 on Laya's tasks with the 12B, most of it spent reading the input. 58 ms p50 for a probe request on the 24-block 4B.BENCHMARKS.md §1, §4c
LicencesTez code MIT. Gemma 4 and Qwen3.5 weights Apache-2.0.LICENSE

Run it locally.

Install Tez, start llama.cpp with the model, then put tez serve in front of it. Clients send requests to http://127.0.0.1:8787/v1/systemone.

Install, start the model, serve
$ pip install git+https://github.com/Jibalmi/Tez$ llama-server -m gemma-4-12b-it-Q8_0.gguf -ngl 99 -c 4096 --port 8091 --swa-full$ tez serve --backend http://127.0.0.1:8091 --template gemma4

The llama-server section of the docs lists the exact flags behind the published numbers. The measured weights are Ollama's gemma4:12b-it-q8_0 GGUF. The equivalent public file, gemma-4-12b-it-Q8_0.gguf in unsloth/gemma-4-12b-it-GGUF, was not separately measured.
